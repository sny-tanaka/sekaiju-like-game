# Issue #41 追補2: 攻撃スキル威力ティアの単調化（上位を明確に強く）

> 「上位スキルがレベル1で180%・下位が160%」のような“あまり強くなっていない”差を解消し、
> **同役割の攻撃スキルは tier ごとに明確な段差（各 ≈1.25×）**を持たせる。
> 対象は**攻撃スキルの威力のみ**（`power` 関数の差し替え）。TP/状態異常付与率/対象/最大Lv/属性は据え置き。

## 0. 方針と安全性

- 監査スクリプトで全攻撃スキルを tree×depth で並べ、**同 target・同役割の prereq チェーン**で段差が小さい
  （≈1.1×）ものを抽出した。中位を上げると上位もカスケードで上げる必要があるため、**クラス横断で
  統一ティアに揃える**（一部クラスだけ強くならないように）。
- **ボス/雑魚/FOE 受け入れシミュ（`balanceSim.test.ts`）が使う標準PTは base スキルのみ**
  （`skill_power_slash`/`skill_triple_strike`/`skill_fire_bolt`/`skill_heal`/`skill_mass_heal`/
  `skill_provoke`/`skill_shield_bash`）。本変更は**master/title スキルのみ**を対象とし base は触らないので、
  シミュは緑のまま＝**基準難易度は不変**。投資ビルド（master技）だけが明確に強くなる（＝狙い通りの上位報酬）。
- **据え置き（変更しない）**:
  - base（d0）攻撃: 狙撃 / パワースラッシュ / 崩拳 / ファイアボルト / アイスボルト / ボルトショック / 吸魂 / 三段突き
  - 多段（per-hit が低い別系統の伸び）: ダブルスラッシュ / ダブルショット / 双掌打 / ブレイドダンス / 連弾 / 七星連撃 / 双剣の舞 / ランページ
  - 低威力の封じ補助（威力1.15前後＋封じ・maxLv3 中心）: 腕封じの矢 / 脚封じの矢 / 頭封じの矢 / 足止めの矢 / 当て身打ち / 点穴突き / 足払い / アームブレイク
  - 状態異常主体の低威力: 毒の呪 / 麻痺の呪
  - 安価な汎用弾: 闇の呪弾（前提に攻撃スキル無し＝段差問題なし。クラス個性として据え置き）
  - 入口AoE: 拡散射撃 / なぎ払い（チェーン起点。上位を上げれば段差は十分）
  - 称号AoE/状態異常: 疫病の散布 / 死波（短い称号ツリーで内部段差問題なし。据え置き）
  - 並列属性（同値が意図）: アイスボルト＝ファイアボルト＝ボルトショック

## 1. 単体攻撃ティア（`power` 差し替え。max5）

| ティア | 新 power(lv) | Lv1→Lv5 | 対象スキル |
| --- | --- | --- | --- |
| 中 | `1.75 + 0.25*lv` | 2.0→3.0 | スピアスラスト / ヘビースイング(+頭封じ) / フレイムブレイド / 貫通の矢 / 冥府の冷気(+麻痺) / 死霊弾 |
| 大 | `2.2 + 0.3*lv` | 2.5→3.7 | エグゼキューション / アーマークラッシュ(+腕封じ) / チャージショット / 昇龍奥義 / サンダーボルト / 崩呪(+麻痺) / 悪夢の呪(+睡眠) |
| 極 | `2.7 + 0.4*lv` | 3.1→4.7 | サベージブロウ / ドラゴンランス / 滅びの一矢 / 羅刹掌 / ラグナロク / 魂喰らい |

- ファイアランス / フロストランス(+麻痺) / ボルトランス は**既に 2.0→3.0**（中位）＝変更不要。
- 各スキルは damage 効果の `power` のみ差し替え。`ailment` 等の付随効果はそのまま。

### 段差確認（例）
- 狩人単体: 狙撃 1.5→2.3 → 貫通の矢 2.0→3.0 → チャージショット 2.5→3.7 → 滅びの一矢 3.1→4.7（×1.33/1.25/1.24）
- 戦士斧: ヘビースイング 2.0→3.0 → アーマークラッシュ 2.5→3.7 → サベージブロウ 3.1→4.7（×1.25/1.24）
- 降霊単体: 吸魂 1.38→2.1 → 死霊弾 2.0→3.0 → 魂喰らい 3.1→4.7

## 4. 実装手順・検証

1. `src/data/battleSkills.ts` の該当スキルの damage 効果 `power` を上表に差し替え（**他フィールドは触らない**）。
2. `yarn gen:docs` で strategy-docs/classes.md・titles.md を再生成。
3. **検証ゲート 3点すべて緑**: `yarn test` / `yarn lint` / `npx tsc -b`。
   - 既存テストでこれらスキルの威力に依存するものがあれば期待値を更新（`combat.ts`式・`balance.ts`・
     `enemies.ts`・`balanceSim.test.ts` の標準PT定義は変更禁止）。**boss/zako/foe sim は base 技のみ使用のため緑のはず**。
4. 監査用スクリプト `src/data/_skillAudit.test.ts`（ディレクターが用意済み）を `yarn vitest run src/data/_skillAudit.test.ts`
   で実行し、出力を確認したうえで**このファイルを削除**（恒久テストではない開発用ダンプ）。
5. **push しない**。`git add -A && git commit` して commit SHA を報告。
