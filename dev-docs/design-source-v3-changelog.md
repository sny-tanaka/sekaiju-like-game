### フレーム構成（v3）
`9a main(操作可)` / `9b intro` / `9c result(新規)` / `9d sequence timeline(新規・仕様)` / `9e 攻撃エフェクト6属性` / `9f 状態異常10種+支援` / `9g defeat` / `9h flee`

### v3 追補（エフェクト/状態異常のフルセット化 — デグレ修正）
- **攻撃エフェクトを 8属性準拠の 6種に拡充**（v2 の「斬/打/刺/魔法」4種 → 仕様 §戦闘の `斬 slash / 突 pierce / 壊 bash / 火 fire / 氷 ice / 雷 volt`）。`atkFire / atkIce / atkVolt` の keyframe を追加。`9a` の敵タップ循環も 6属性に変更。無 almighty は火を流用。
- **状態異常を 10種フルで掲出**（v2 の 毒/麻/眠 3種 → 仕様 §戦闘の 毒/麻痺/睡眠/盲目/混乱/呪い/即死/頭封じ/腕封じ/脚封じ）。各々に角バッジ色・記号（バインド系🔒 / その他🌀）を定義し `9f` に一覧化。味方カードの角バッジもこの体系を流用。
- 敵カードの弱点チップ・対象情報パネルの属性表記を仕様準拠（炎→火 等）に統一。`9d` の属性→FX 対応表も `斬/突/壊/火/氷/雷` に修正。

## C. 実装への引き継ぎ
- **削除**項目はモックから消えている＝実装不要。**追加**項目はモック維持＝記載どおり機能仕様に取り込む。これで「モック忠実度 = 機能要件」になり実装側のジャッジが消える。
- 戦闘の動的データ（敵耐性/弱点・対象情報パネル・召喚リボン・状態異常バッジ）は `9a` のロジッククラスにサンプル実装あり。`previewTurnOrder()` の戻りを行動順帯に流し込む想定。
- SkillTree（4b）は据え置き。デザイン判断が必要になったら別途依頼ください。
