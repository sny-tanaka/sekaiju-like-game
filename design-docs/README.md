# 世界樹の迷宮ライク ゲーム設計書

本ディレクトリは、世界樹の迷宮Ⅴ（[システム解説](https://w.atwiki.jp/sekaiju_mazev/pages/5.html)）のゲームシステムを参考に、本リポジトリ（React 19 + TypeScript + Vite の SPA/PWA）で自作する「世界樹ライク」3DダンジョンRPGの設計をまとめたものです。

> 本書は **元ゲームの仕様をそのまま再現する** ものではなく、コア体験を抽出して自作ゲームの機能要件・データモデルとして再構成したものです。著作物・固有名詞（職業名・キャラ名など）はそのまま使わず、設計上の参照に留めます。

## このゲームのコア体験（何を作るのか）

世界樹の迷宮の面白さを支える3本柱を、本作でも中核に据えます。

1. **手描きマッピング探索** — プレイヤー自身が地図を描きながら危険な迷宮を踏破する達成感
2. **戦略的ターン制バトル** — 行動順・隊列・属性・状態異常・バフ/デバフを読み合う重量級の戦闘
3. **ギルド育成と編成構築** — 種族 × 職業 × スキルツリーの組み合わせでパーティを構築する自由度

## スコープ方針（グラフィックは作り込まない）

本作は自作ゲームであり、**グラフィックは作り込まない**方針です。そのため以下の「飾り要素」は実装対象外とします。

- キャラクターの外見カスタマイズ（立ち絵・髪/目/肌の色など）
- ボイス選択

キャラクターはアイコンや簡易な見た目区分＋名前で識別する程度に留め、**ゲームメカニクス（マッピング・戦闘・育成）に注力**します。ダンジョン描画もMVPではグリッドベースの2D俯瞰で成立させ、3D表現は後回し（任意）とします。

## 技術方針（本リポジトリの制約に合わせる）

- **フロントエンドのみのSPA/PWA**。サーバ・DBは持たず、ゲーム状態は **クライアントに永続化**する。
  - セーブデータ・図鑑・地図など大きめのデータ → **IndexedDB**（`idb` などのラッパー想定）
  - 軽量な設定 → localStorage
- **状態管理**: ゲーム本体の進行状態（パーティ・所持品・現在地・戦闘）は単一の `GameState` ツリーで管理。React Context + `useReducer`（必要に応じて Zustand 等の軽量ストア）で実装する。状態更新は **純粋な reducer / ドメイン関数** に寄せ、UIから切り離してテスト可能にする。
- **描画レイヤー**:
  - ダンジョン3D表示 → 当面は擬似3D（プリレンダ背景＋方向）か、将来的に `three.js` / WebGL。**MVPではグリッドベースの2D俯瞰でも成立する**設計にする。
  - 手描きマップ → `<canvas>`（描画パレット・アイコン配置・オートパイロット線）。
- **ロジックとビューの分離**: ダメージ計算・行動順決定・エンカウント抽選などは `src/` 内の純関数モジュールに置き、`vitest` で単体テストする。乱数は注入可能にして再現テストできるようにする。
- **データ駆動**: 種族・職業・スキル・敵・アイテムは **TypeScript の定数定義（マスターデータ）** として持ち、ロジックはデータを参照するだけにする。バランス調整＝データ編集で完結させる。

## 用語集（本作の呼称）

元ゲームの固有名詞は使わず、本作の一般名称で統一します。

| 本作の用語 | 意味（元ゲーム対応） |
| --- | --- |
| ギルド | 冒険者パーティの母体。所属キャラ・所持金・図鑑を管理する単位 |
| 隊列（フォーメーション） | 前衛/後衛の配置。被ダメージ・攻撃射程に影響 |
| 種族 | 基本ステータスと固有スキル（ユニオンスキル）を決める区分 |
| 職業（クラス） | 装備適性とスキルツリーを決める区分。転職で変更可 |
| 称号（二つ名） | 職業に追加できる第2スキルツリー。成長傾向が変化する |
| 徘徊型エネミー（FOE相当） | 迷宮内を移動する強敵。回避・誘導・撃破の対象 |
| ユニオンゲージ | 蓄積して必殺技（ユニオンスキル）を撃つためのゲージ |
| マッピング | プレイヤーが手描きで地図を完成させる探索の中核要素 |

## 実装フェーズ（推奨ロードマップ）

MVPから段階的に積み上げる。各ドキュメントの末尾に「MVP優先度」を併記する。

- **Phase 0: 基盤** — `GameState` 構造・IndexedDB セーブ/ロード・画面ルーティング・マスターデータ駆動の土台
- **Phase 1: 探索 MVP** — グリッド迷宮の移動 + 手描きマップ（壁線/床塗り/アイコン）+ ランダムエンカウント
- **Phase 2: 戦闘 MVP** — 隊列・ターン制・基本スキル・SP・状態異常・勝敗処理
- **Phase 3: 育成** — 種族/職業/スキルツリー/レベルアップ/装備
- **Phase 4: 拡張** — FOE・ユニオンスキル・召喚・採集/料理・鍛冶・転職/引退/称号
- **Phase 5: メタ** — 図鑑・クエスト・周回引き継ぎ・PWAオフライン対応
