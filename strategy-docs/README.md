## 1. キャラクター構築の全体像

1人のキャラは **種族 × 職業 × スキル振り × 称号** で個性が決まります。

- **種族**: 基礎ステータスと成長傾向、固有の**ユニオンスキル**・**採集スキル**・**種族パッシブ**を持つ。種族は作成時に確定し、**転職しても変わらない**。
- **職業**: スキルツリー（基本＋達人＋パッシブ）と装備適性を規定。作成時に種族と独立に自由選択でき、後から**転職**で変更できる。
- **称号（二つ名）**: 到達階20で解放される第2スキルツリー。成長傾向の補正も付く。
- **隊列**: 前衛3 / 後衛2 の最大5人。後衛は近接物理の与/被ダメージが 0.7 倍（独立に乗算）。

### レベル・SP・成長

- 素ステータスは線形成長: `stat(Lv) = 初期値 + 成長 × (Lv − 1)`。**レベル上限は100**。
- レベルアップごとに **SP を平均 +1.62**（+1 か +2 を配分。**Lv100 で総 SP ≈ 160**）。**スキルは Lv で自動習得されず、SP を振って習得・強化する**。
  - **1段階上げる消費 SP は「前提チェーンの深さ」で決まる**。基本（前提なし）は 1、前提のある段は一律 2（緩やかな逓増）。
    | 深さ（段） | T1(0) | T2(1) | T3(2) | T4(3) | 5段以降 |
    | --- | --- | --- | --- | --- | --- |
    | 1Lvの消費SP | 1 | 2 | 2 | 2 | 2 |
  - 自職フル（職業＋称号1つ＋種族）の必要SPは概ね **145〜190**（職業間の差を小さく調整）。**Lv100 の総SP≈160 とほぼ拮抗**し、軽い職はちょうど取り切れ、火力が厚い職は取捨選択／転生のボーナスSPで補う。
  - スキルツリーの「前提」を満たすと解放（例: 「なぎ払い」は「パワースラッシュ Lv2」が前提）。
  - 各職業ツリーの**先頭スキルは作成/転職時に Lv1 で無料習得**済み。
- **転職**: レベル −5。職業ツリー・称号ツリーのスキル振りはリセット（種族スキルは保持）。称号は外れる。
- **転生**: Lv30 以上で可能。キャラを作り直し、転生時Lvに応じたステ／SP ボーナスを得る（開始Lvは転生時の半分・上限30）。
- **称号習得**: 到達階20で解放。1職2種から1つ選ぶと第2ツリーが開き、**SP+5**。

## 2. 戦闘の基礎

- 一括入力のターン制。各ターン、全員のコマンドを決めてから **実効AGI の高い順**に解決（同値は乱数）。
- コマンド: 攻撃 / スキル / 防御（pdef・mdef ×1.5・1ターン）/ どうぐ / 逃走 / ユニオン。
- TP は毎ターン終了時に **最大TPの5%** 自然回復。

### ダメージ計算（除算型）

戦闘用の派生値は素ステから算出します（バフ・パッシブを乗算）。

```
物理攻撃 patk = STR×2 + 装備ATK
物理防御 pdef = VIT×2 + 装備DEF
魔法攻撃 matk = INT×2 + 装備MAT
魔法防御 mdef = MND×2 + 装備MDF
```

1ヒットのダメージ（**DEF_K=120**・Phase 6-4 確定値）:

```
base      = 攻撃力 × スキル威力
軽減後     = base × 120 / (120 + 防御力)        ← 除算型（DEF_K=120: 旧100から引き上げ）
最終       = 軽減後 × 属性倍率 × 隊列補正 × ばらつき(0.95〜1.05) × (会心なら 1.5)
```

- **属性**: 弱点 ×1.5 / 等倍 ×1.0 / 耐性 ×0.5 / 無効 ×0。属性は 斬・突・壊（物理）/ 火・氷・雷（魔法）/ 無（almighty=貫通）。
- **命中（物理のみ。魔法は必中）**: `命中率 = clamp(0.9 + (命中 − 回避)×0.01 − 盲目0.5, 0.3, 1.0)`。
- **会心**: `会心率 = clamp(0.05 + (LUC差)×0.005 + パッシブ補正, 0.02, 0.5)`、会心倍率 ×1.5。
- **隊列補正**: 近接物理は攻撃側後衛・防御側後衛がそれぞれ ×0.7。

### 回復スキル（魔力連動・Phase 6-4 確定）

回復量は「flat + 詠唱者 matk × 係数」でスケールします（進行で回復が伸びる）。

```
回復量 = round(flat + casterMatk × coef)
  単体回復（ヒール系）:   coef = 0.70、flat = 20 + 5×lv
  全体回復（マスヒール等）: coef = 0.45、flat = 10 + 3×lv
  軽回復（救護指示・癒しの歌）: coef = 0.30、flat = 8 + 2×lv
```

アイテムの回復（ポーション等）は固定値のまま（ステ非連動）。

### TP 自然回復

毎ターン終了時に **最大TPの4%**（小数切り上げ）回復します（Phase 6-4 確定: 旧5%→4%）。長期戦での TP 消耗が効くようになり、スキル連打が難しくなっています。

### 強化 / 弱体（バフ・デバフ）

- 倍率制・残ターン制。同じ `stackGroup`（例 `atkBuff`）内では「1.0 からの乖離が最大」の1つだけ採用し、グループをまたいで乗算。
- 1要素あたり 0.5〜1.5、最終 0.25〜2.0 にクランプ。デバフは倍率 < 1.0 のバフとして扱う。

### 状態異常・封じ

| 状態 | 効果 |
| --- | --- |
| 毒 | 毎ターン終了時に最大HPの5%ダメージ |
| 麻痺 | 30%の確率で行動不能 |
| 睡眠 | 行動不能。**被ダメージで解除** |
| 盲目 | 物理命中が大きく低下 |
| 腕封じ | 通常攻撃・物理スキルが使えない |
| 頭封じ | 魔法・補助スキルが使えない |
| 脚封じ | 回避がほぼ0・逃走不可 |

- 付与確率は `基礎確率 × (1 + LUC差×0.01)`、上限95%。

### 逃走率（Phase 6-4 確定）

```
逃走率 = clamp(0.4 + (味方平均AGI − 敵平均AGI)×0.02, 0.05, 0.9)
ボスが含まれる → 逃走不可（rate=0）
FOEが含まれる → 上記の0.5倍
```

## 3. パッシブスキル（常時効果）

習得しているだけで常時効果を発揮します（戦闘中に「撃つ」ものではありません）。

- **倍率系**（物理/魔法攻撃・防御、命中、回避、最大HP/TP）は**乗算合成**、**クリ率は加算合成**。
- **武器マスタリー**（例「剣の心得」）は、対応する武器種を**装備している時のみ**有効。
- 最大HP/TP のパッシブは戦闘開始時の最大値に反映されます。
- 種族パッシブは転職で保持、職業/称号パッシブは転職でリセットされます。

## 4. 反応系スキル（構え・挑発・障壁）

「構え」を取ると数ターンの間、特定条件で自動的に反応します。**多段ヒットのスキルでも、反応は「行動 × 対象」につき1回**に制限されます（過剰発動の防止）。

| 種別 | 付与先 | 発動条件と効果 |
| --- | --- | --- |
| 連携追撃（chase） | 自分 | **味方**が、構えを取った時のスキルと**同じ属性**で敵にダメージを与えると、その敵へ追撃する（無属性はワイルドカード）。戦士「連刃の構え」など。 |
| 反撃（counter） | 自分 | **敵**から攻撃を受けて生存していると、確率で反撃する。反撃はさらなる反応を誘発しない。拳聖「クロスカウンター」、守護兵「カウンターガード」など。 |
| 挑発（decoy） | 自分 | 敵のターゲット抽選で**狙われやすくなる**（基本重み1＋挑発の重み）。守護兵「挑発」。 |
| 障壁（barrier） | 味方全体など | 被弾ダメージを**総吸収量まで肩代わり**する。吸収を使い切るか期限が切れると消える。守護兵「ラインガード」、降霊術士「無慈悲な盾」。 |
| 治療（cleanse） | 味方 | 対象の状態異常（封じ含む）を**全解除**する。薬師「リフレシュハーブ」など。 |

## 5. 召喚体・ユニオン

- **召喚体**: 同時最大3体。最前列の壁／攻撃役として味方側で行動する（[summons.md](./summons.md)）。`buffImmune` の個体（石像・亡者の壁）は強化弱体・状態異常を受けない。
- **ユニオンスキル**: 種族固有の必殺技。ユニオンゲージ（戦闘行動や被弾、戦闘終了で蓄積）を消費し、宣言ターンの冒頭に解決（通常行動は消費しない）。発動にはゲージ100%、必要人数ぶんの参加者が要る。

## 6. 適正レベル・ティア（Phase 6-4 確定）

各ボス階の推奨レベルと装備ティア。「同帯の雑魚を1〜2ターンで倒せるようになったらボス挑戦の合図」。

| ボス階 | 適正Lv | 装備ティア | テーマ |
| --- | --- | --- | --- |
| F10 | 12 | 1 | 森・洞窟 |
| F20 | 23 | 2 | 岩山・獣 |
| F30 | 35 | 3 | 氷雪 |
| F40 | 47 | 4 | 雷雨・嵐 |
| F50 | 60 | 5 | 瘴気・不死 |
| F60+ | 72/83/92/98/100 | 5（循環） | 全帯ループ（敵名に LvN） |

- FOE の適正Lvは前後ボスの中間（例: F16 FOE → (12+23)/2 ≈ 17）。
- F60以降は tier0〜4 の敵が循環して再登場（`enemyScale` で強化、装備も循環ティア）。
