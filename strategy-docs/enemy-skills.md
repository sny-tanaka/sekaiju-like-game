## 3. ボス専用行動表（F10〜F50）

### アクション選択アルゴリズム

1. 条件を満たすアクションを収集（cooldown・hpBelow/Above・minTurn・maxUses）
2. 通常攻撃（weight=10）を常に候補に追加
3. weight で重み付き抽選

**激昂（enrage）の解禁タイミング**: 自HP が 50% 以下になった瞬間から、weight=8 の高重みで選択され始める。回復を怠ると瞬殺される危険性が上がる。

## 4. 受け入れ基準との対応

| 基準 | 関連アクション |
| --- | --- |
| AC1: ボス18〜22ターン・minHP≤15% | 激昂（HP50%で追加脅威）＋高HP設定 |
| AC3: FOE 6〜10ターン・被ダメ1.3〜1.6倍 | 強打×1.6・戦吼バフで雑魚より手強く |
| AC4: 全敵が条件付きスキル使用 | kit/actionsで全敵にcond付きアクション |
