# 種族（レース）一覧

> 基礎ステータスは種族で決まり、Lvごとに成長値ぶん上昇する（`stat(Lv) = 初期値 + 成長 × (Lv-1)`）。種族スキル（ユニオン・採集・種族パッシブ）は**転職しても保持**される。
