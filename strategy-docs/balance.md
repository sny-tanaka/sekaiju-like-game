## 転生（REBIRTH）

> 仕様: Lv100到達時のみ可能。転生後はLv1から再スタート。永続ボーナスは累積（転生のたびに加算・頭打ちなし）。ボーナスは転生時に選んだ種族の成長傾向に応じて配分。

| 定数 | 値 | 意味 |
| --- | --- | --- |
| STAT_TOTAL | 240 | 1回の転生で配る全ステ合計ボーナスポイント（基準30×8ステ）。種族傾向で按分。 |
| BONUS_SP | 10 | 1回の転生で得る追加SP（種族非依存・固定・累積） |

### 配分式

```
avgGrowth[key] = (Σ_r RACES[r].statGrowth[key]) / N  // 全種族のステ別平均成長
w[key]         = RACES[raceId].statGrowth[key] / avgGrowth[key]  // 対象種族の相対重み
sumW           = Σ_key w[key]
bonus[key]     = Math.round(STAT_TOTAL × w[key] / sumW)  // 合計がSTAT_TOTALになるよう正規化
```
